# Android application

This directory is reserved for the UI track's Kotlin and Jetpack Compose application. No Android implementation exists yet.

The application should keep inference behind a `VisionEngine` interface and begin with a mock implementation. Camera, motion-sensor, speech, accessibility, preferences, and emergency interactions belong here. Model tensor details must wait for an agreed contract and compatible export.

See [project context](../docs/PROJECT_CONTEXT.md) and [integration guidance](../docs/INTEGRATION.md).
