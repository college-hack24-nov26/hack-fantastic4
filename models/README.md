# Model delivery

Do not commit training checkpoints, datasets, or generated model binaries here. A future approved model delivery should provide a compatible artifact, a manifest, integrity hash, labels, preprocessing and output specifications, runtime requirements, and evaluation notes. Large final artifacts may require Git LFS or a release asset after the team agrees on distribution.

The current manifest schema is a draft metadata envelope. It does not establish an inference format or guarantee Android compatibility. See [integration guidance](../docs/INTEGRATION.md).
